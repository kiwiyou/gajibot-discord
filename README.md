# gajibot

## 명령어 일람

- `d/D <검색어>`

[다음 사전]에서 `<검색어>`를 검색합니다. 가장 관련성 있는 하나의 항목이 임베드로 표시됩니다. 현재 영어사전/영영사전/한국어사전/일본어사전을 지원합니다.

## 실행 방법

아래 환경변수를 설정하고 실행합니다.

```
TOKEN=<디스코드 봇 토큰>
DAUM_IDK_EMOJI=<다음 사전 검색 결과가 없을 때 표시되는 이모지>
DAUM_LOADING_EMOJI=<다음 사전 검색 중일 때 표시되는 이모지>
DAUM_MAYBE_URL=<다음 사전 검색어 제안 시 표시되는 이미지 URL>
```

[다음 사전]: https://dic.daum.net
